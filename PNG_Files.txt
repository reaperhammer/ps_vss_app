## Icon Design Guidelines

### Color Scheme
- **Primary Color:** #2196F3 (Blue)
- **Success Color:** #4CAF50 (Green)
- **Warning Color:** #FF9800 (Orange)
- **Error Color:** #F44336 (Red)
- **Text Color:** #212121 (Dark Gray)

### Style Requirements
- **Style:** Flat design, minimal shadows
- **Background:** Transparent PNG with alpha channel
- **Borders:** None or very subtle
- **Consistency:** All icons should follow the same design language

### File Format
- **Format:** PNG with transparency
- **Color Depth:** 32-bit RGBA
- **Compression:** Optimized for file size while maintaining quality

## Implementation Notes
- Icons will be referenced in XAML using relative paths: `.\assets\png\iconname.png`
- All icons should be optimized for display at their specified sizes
- Consider creating @2x versions for high-DPI displays if needed
- Icons should be clearly visible against both light and dark backgrounds

## Priority Order
1. **High Priority:** refresh.png, create.png, delete.png (core functionality)
2. **Medium Priority:** volume.png, shadowcopy.png (tab icons)
3. **Low Priority:** status icons and app_icon.png (enhancement)
